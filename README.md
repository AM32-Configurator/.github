# .github
AM32 Configurator — инструмент для настройки и обслуживания ESC с открытой прошивкой AM32. Позволяет подключаться к совместимым регуляторам, читать и изменять параметры, настраивать направление вращения, PWM, телеметрию и другие параметры ESC, а также выполнять обновление firmware для FPV-дронов и RC-моделей.
