## Обзор проекта

**AM32 Configurator** — инструмент для конфигурации электронных регуляторов скорости (**ESC**), работающих на открытой прошивке **AM32**. Экосистема AM32 применяется в FPV-дронах, мультикоптерах, самолётах и других RC-проектах и предоставляет пользователю расширенный контроль над параметрами работы бесколлекторного двигателя.

Configurator позволяет подключаться к совместимому ESC, считывать его текущую конфигурацию и изменять доступные параметры без необходимости вручную работать с низкоуровневыми настройками контроллера. В зависимости от версии AM32 и конкретного ESC могут быть доступны направление вращения двигателя, параметры запуска, PWM, торможение, телеметрия и другие настройки.

Программа также используется при обслуживании и обновлении firmware AM32. Перед прошивкой необходимо точно определить аппаратную платформу ESC и убедиться, что выбранная версия firmware предназначена для установленного микроконтроллера и конкретной платы.

## AM32 Firmware и ESC

**AM32** — открытая firmware для ESC, ориентированная на управление бесколлекторными двигателями. Она используется на различных регуляторах и микроконтроллерах, поэтому при обновлении особенно важно правильно определить hardware target.

Configurator предоставляет более удобный интерфейс для работы с такими ESC. Вместо изменения параметров непосредственно через полётный контроллер пользователь может просмотреть конфигурацию регулятора и изменить необходимые значения через специализированный интерфейс.

Перед экспериментами с настройками рекомендуется сохранить исходные значения. Некорректные параметры запуска, тайминга или других характеристик ESC могут привести к нестабильной работе двигателя.

## FPV, Betaflight и ESC

| Компонент | Применение |
|---|---|
| **AM32** | Firmware электронного регулятора скорости |
| **ESC** | Управление бесколлекторным двигателем |
| **Flight Controller** | Управление ESC со стороны полётного контроллера |
| **Betaflight** | Популярная платформа для FPV-мультикоптеров |
| **INAV** | Использование в совместимых UAV-конфигурациях |
| **DShot** | Цифровое управление совместимыми ESC |
| **Telemetry** | Передача поддерживаемых данных ESC |
| **Bidirectional DShot** | Использование при поддержке всей конфигурацией |

В FPV-квадрокоптере настройки ESC работают совместно с конфигурацией полётного контроллера. После изменения направления вращения двигателя необходимо убедиться, что реальное направление соответствует Motor Direction, заданному в используемой полётной прошивке.

Параметры протокола управления также должны соответствовать возможностям ESC и настройкам Betaflight, INAV или другой системы управления.

## Настройка и обновление

При первом подключении рекомендуется считать существующие параметры всех ESC и проверить, что устройства определяются корректно. Если конфигуратор поддерживает сохранение настроек, полезно создать резервную копию рабочей конфигурации.

Для обновления firmware необходимо использовать сборку AM32, предназначенную именно для аппаратной платформы конкретного ESC. Совпадение производителя или внешнего вида платы само по себе не гарантирует совместимость firmware.

После прошивки необходимо повторно проверить параметры каждого регулятора, направление двигателей и стабильность их запуска. Первоначальную проверку FPV-мультикоптера следует выполнять без установленных пропеллеров.

## Быстрый старт

1. Снимите пропеллеры с FPV-дрона перед настройкой.
2. Подключите совместимый AM32 ESC или полётный контроллер.
3. Запустите **AM32 Configurator**.
4. Установите соединение с устройством.
5. Считайте текущие параметры ESC.
6. Сохраните исходную конфигурацию при наличии такой возможности.
7. Измените необходимые параметры.
8. Запишите новую конфигурацию в ESC.
9. При обновлении firmware убедитесь в правильности hardware target.
10. Проверьте запуск и направление каждого двигателя без пропеллеров.
